# 🧮 Web Calculator

A sleek, modern, and web-based calculator built using pure HTML, CSS, and JavaScript.

## ✨ Features

* **Clean User Interface:** Styled with a dark-mode theme and clear button layout.
* **Full Arithmetic Operations:** Supports addition, subtraction, multiplication, division, and percentages.
* **Error Handling:** Gracefully handles invalid mathematical expressions without breaking.
* **Backspace & Clear Controls:** Includes `AC` (All Clear) and `⌫` (Backspace) functionality for quick corrections.
* **Pure JavaScript:** Built completely with native JS without relying on external libraries or frameworks.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and layout.
* **CSS3:** Flexbox, Grid layout, and custom styling.
* **JavaScript (ES6):** Dynamic event handling and mathematical processing.
